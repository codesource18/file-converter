# File Converter

A modern, privacy-first PDF and image toolkit for converting, editing, compressing and transforming files directly from the browser.

> **Your Files. Your Browser. Nothing Stored.**

File Converter is designed to make common file operations fast, simple and private while providing a polished liquid-glass interface and intelligent format detection.

## Smart File Detection

Users do not need to choose a converter before uploading a file.

Drop a file into File Converter and the application:

1. Inspects its actual format.
2. Detects the file using signatures / MIME information.
3. Displays the three most relevant conversion options.
4. Shows additional compatible tools.
5. Chooses local or compatibility processing automatically.
